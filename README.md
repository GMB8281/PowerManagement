# PowerManagement #

<img src="https://gitlab.com/GMB8281/PowerManagement/-/raw/master/app/src/main/ic_launcher-playstore.png?ref_type=heads" width="200"/> 

App for managing different profiles on SmartPack Kernel Manager, featuring a Quick Settings shortcut via the Tasker API. It also includes an Extreme Battery Saver mode, which disables all apps except for those you choose.

Enjoy!
